# Nevergoodstudy

我在维护 **NETworkManager for macOS**，一个面向网络工程与运维的原生 macOS 工作台。它用 SwiftUI 和 AppKit 实现，在同一个应用里提供资产管理、网络诊断和 SSH 终端。

I maintain **NETworkManager for macOS**, a native workbench for network engineers and administrators. Built with SwiftUI and AppKit, it brings asset management, network diagnostics, and an SSH terminal into one macOS app.

**[项目仓库 · Project repository](https://github.com/Nevergoodstudy/NETworkManager-macOS)** · [使用与构建 · Usage and build](https://github.com/Nevergoodstudy/NETworkManager-macOS/blob/main/macos/README.md)

本项目是 [BornToBeRoot/NETworkManager](https://github.com/BornToBeRoot/NETworkManager) 的独立 macOS 适配。  
The project is an independent macOS adaptation of the upstream NETworkManager.
